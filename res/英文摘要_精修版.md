# English Abstract

With the rapid development of social media platforms and online communities, text has become one of the most important carriers for information dissemination and opinion expression on the Internet. Under this background, text memes with templated, repetitive and highly replicable forms have emerged in large numbers. Some of these expressions spread prejudice through group labeling, implicit sarcasm and offensive language, which poses new challenges to online content governance. To address this problem, this thesis focuses on the research and design of a machine-learning-based text meme recognition system for Chinese text scenarios.

Based on a front-end and back-end separated architecture, this work builds three experimental routes: a baseline model, a meme-expression-feature-enhanced model, and a BERT-based model. The baseline model uses character-level TF-IDF and Logistic Regression for binary text classification. The meme-feature model introduces handcrafted features such as templated expressions, group references, emotional intensifiers, online phrases and context disambiguation in order to improve adaptation to text meme scenarios. The BERT model adopts the Chinese pre-trained model `bert-base-chinese` for fine-tuning so as to improve contextual semantic understanding.

Experiments are conducted on both a formal test set and a manually constructed test set. The results show that the BERT model achieves the best overall performance on the formal test split, with an accuracy of 0.8887 and an F1 score of 0.8680, indicating its strong ability in general Chinese semantic classification tasks. However, on the manually constructed meme-oriented test set, the meme-feature model performs better on templated attack expressions and implicit group attacks, which are more closely related to the target scenario of this thesis. This finding suggests that overall benchmark performance is not always consistent with scenario-specific recognition ability, and that text meme recognition should combine statistical features, scenario-oriented features and semantic models for comprehensive analysis.

The implemented system supports text input, result display, history records, model comparison and experiment management, and can satisfy the requirements of system implementation, experimental analysis and thesis defense. The study demonstrates that text meme recognition in Chinese scenarios has both theoretical and practical value, and provides a useful reference for future work on multimodal meme recognition and complex online expression analysis.

**Keywords:** text meme recognition; machine learning; harmful text detection; BERT; online content governance
