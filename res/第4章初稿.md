# 第4章 实验与结果分析

## 4.1 实验环境与评价指标

为了全面评估本文所构建系统的识别能力，本文在实验设计上采用了“正式测试集 + 人工测试集”相结合的方式，并围绕基线模型、模因式表达特征模型以及 BERT 模型三条实验路线展开对比。正式测试集实验主要用于衡量模型在标准二分类任务上的整体性能，而人工测试集实验则用于观察模型在文本模因场景下的具体行为差异，尤其是对模板化表达、隐含群体攻击和反对语境文本的适配能力。

### 4.1.1 实验环境

本文实验环境可以分为两部分：传统模型实验环境和 BERT 模型实验环境。

1. **传统模型实验环境**
   传统机器学习模型的训练、保存、加载和接口联调主要在本地开发环境中完成。系统整体采用前后端分离架构，前端基于 Vue 3 构建，后端基于 FastAPI 实现，模型训练和实验脚本则独立运行。传统模型训练成本较低，因此适合在本地快速完成多轮实验与规则调整。

2. **BERT 模型实验环境**
   BERT 模型正式训练在远程 GPU 环境中完成，使用中文预训练模型 `bert-base-chinese` 进行二分类微调。远程环境中 GPU 型号为 RTX 3090，显存为 24GB，Python 版本为 3.10.8。通过该环境完成了 smoke test 验证和正式训练，并保存了模型目录、指标文件与元数据文件。

在模型管理方面，传统模型通过 `joblib` 文件进行保存和加载，BERT 模型则通过 Hugging Face 风格目录保存，并输出 `metrics.json` 和 `metadata.json` 等文件，以保证实验过程具备可复现性。

### 4.1.2 评价指标

为了保证不同模型之间的结果可比较性，本文使用以下四项指标对模型进行评价：

1. **准确率（Accuracy）**  
   准确率表示被正确分类的样本数量占全部样本数量的比例，用于衡量模型的整体分类能力。

2. **精确率（Precision）**  
   精确率表示模型判定为“疑似有害文本”的样本中，真正属于该类别的比例。该指标能够反映模型对风险文本判断的准确程度。

3. **召回率（Recall）**  
   召回率表示所有真实风险文本中，被模型成功识别出的比例。该指标能够反映模型对目标样本的覆盖能力。

4. **F1 值（F1-score）**  
   F1 值是精确率和召回率的调和平均值，能够综合评价模型的分类效果，是本文对比不同模型时的重要参考指标。

在正式测试集实验中，本文主要以 accuracy、precision、recall 和 F1 值作为量化评价依据；在人工测试集实验中，则进一步结合具体样例表现，对模型的目标场景适配能力进行分析。

## 4.2 正式测试集实验结果

### 4.2.1 三种模型的整体指标

在正式测试集上，本文分别对基线模型、模因式表达特征模型和 BERT 模型进行了比较，结果如下：

1. **基线模型（TF-IDF + Logistic Regression）**
   - Accuracy：0.8223
   - Precision：0.7754
   - Recall：0.8025
   - F1：0.7887

2. **模因式表达特征模型（meme_features_v1）**
   - Accuracy：0.8200
   - Precision：0.7831
   - Recall：0.7810
   - F1：0.7820

3. **BERT 模型**
   - Accuracy：0.8887
   - Precision：0.8515
   - Recall：0.8851
   - F1：0.8680

从上述结果可以看出，BERT 模型在四项指标上均优于前两种模型，尤其是在 accuracy 和 F1 值上表现最为突出。这说明预训练语言模型在通用中文文本语义分类任务中具有更强的表达能力和整体判别能力。

### 4.2.2 基线模型与模因特征模型对比

从基线模型和模因特征模型的对比来看，二者在正式测试集上的总体差异并不大。基线模型 F1 值为 0.7887，而模因特征模型 F1 值为 0.7820。从整体指标上看，模因特征模型并未超过基线模型，甚至略有下降。

这一结果说明，人工设计的模因式表达特征虽然能够增强模型对特定表达结构的敏感性，但在通用测试集上不一定带来整体性能提升。其原因可能在于，正式测试集中的大部分样本仍以一般有害文本和一般正常文本为主，而不是专门针对模因式表达构造的场景样本。因此，人工特征的专项优势在标准测试集上不一定能够充分体现。

### 4.2.3 BERT 模型的优势

相较于传统模型，BERT 在正式测试集上的表现明显更优，这说明其在上下文语义理解方面具备更强能力。基于预训练机制，BERT 能够从句子整体语义和上下文结构中提取更丰富的信息，而不是仅依赖显式词汇特征或浅层表达模式。这一优势使其在标准文本分类任务中取得了最好的整体指标，也为本文后续关于“通用语义能力”和“目标场景能力”之间差异的讨论提供了基础。

## 4.3 人工测试集实验结果

### 4.3.1 人工测试集的构造思路

为了更准确地观察模型在文本模因场景中的表现，本文在正式测试集之外，人工构造了一组补充测试样例。该人工测试集并非用于替代正式测试集，而是作为定性分析和案例分析的重要依据。样例类别主要包括：

1. 正常文本样例；
2. 反对歧视、描述性分析等“反对语境”样例；
3. 一般负面评价或普通分歧样例；
4. 安全网络梗表达样例；
5. 显式有害文本样例；
6. 模因式攻击文本样例；
7. 隐含群体攻击文本样例。

通过这样的分类方式，本文可以更有针对性地观察不同模型在具体目标场景中的适配能力和误判情况。

### 4.3.2 三模型在人工测试集上的总体准确率

在人工测试集上，三种模型的总体准确率如下：

1. 基线模型：0.7667
2. 模因式表达特征模型：0.7333
3. BERT 模型：0.6000

这一结果与正式测试集中的表现形成明显对比。在正式测试集上，BERT 模型总体最优；而在人工测试集上，BERT 的总体准确率却最低。这表明，正式测试集上的高指标并不能完全代表模型在文本模因场景中的具体表现。

### 4.3.3 分类别结果观察

从人工测试集的分类别结果来看，不同模型具有不同特点：

#### （1）正常文本与反对语境文本

在 `normal_plain`、`anti_hate`、`disagreement` 和 `safe_meme` 等类别中，三种模型整体表现都较稳定。尤其是在“我反对任何形式的歧视言论”“这种说法像是在侮辱别人”这类语义上并不属于攻击表达的句子中，经过语境消歧后的传统模型和 BERT 均能够给出较为合理的判断。

#### （2）显式有害文本

在 `explicit_harm` 类别中，基线模型和模因特征模型对一部分显式有害表达能够正确识别，BERT 在部分样例上也表现良好，但并未做到全部正确。这说明 BERT 虽然在正式测试集上整体强于传统模型，但对于人工构造、表达更明确的某些风险样例，其判断并不总是稳定。

#### （3）模因式攻击文本

在 `meme_harm` 类别中，模因式表达特征模型相较 BERT 更符合课题目标。BERT 在这类样例上的表现相对较弱，说明当前微调得到的 BERT 模型更多学到的是一般有害文本分类规律，而不是对“文本模因式攻击表达”这种特定场景进行专项适配。

#### （4）隐含群体攻击文本

在 `implicit_group_attack` 类别中，三种模型都存在一定不足，但 BERT 的表现尤其不理想。这说明面对不包含强烈显式攻击词、而是通过语境暗示和群体概括完成攻击的文本时，模型识别仍然具有较大难度。

## 4.4 三模型结果分析

### 4.4.1 总体指标与目标场景能力的差异

本文实验中最值得关注的现象是：BERT 在正式测试集上的总体指标最好，但在人工构造的目标场景测试集中并不占优；模因特征模型虽然总体指标不如 BERT，但在模因式攻击表达和特定场景样例上更有针对性。

这一现象说明，总体测试集上的高性能与目标场景下的强适配能力并不完全一致。正式测试集更偏向于标准二分类评价，因此更容易体现预训练语言模型的通用语义优势；而人工测试集则更强调具体模因场景中的表达模式和文本结构，因此更容易体现人工特征设计的针对性价值。

### 4.4.2 BERT 模型的优点与局限

BERT 的主要优点在于其对上下文语义的整体建模能力较强，在正式测试集上的四项指标都优于其他模型，表明其在通用文本分类任务中具有明显优势。

但同时，BERT 的局限也较为明显：当前训练数据主要面向一般有害文本分类，而并非专门针对模因式表达构造，因此模型所学到的更多是“通用风险文本规律”，而非“模因表达的专项模式”。这使得 BERT 在面对“不是我说”“某些人又开始这一套了”这类更接近网络模因表达的样例时，未能体现出预期优势。

### 4.4.3 模因特征模型的价值

模因式表达特征模型虽然在正式测试集上的总体表现不占优，但它在人工构造的模因式攻击样例中更能体现课题方向。这说明人工设计的场景特征对于文本模因识别任务具有重要意义。换言之，如果研究目标不仅是“做一个总体指标高的文本分类器”，而是“做一个更贴近文本模因识别场景的模型”，那么模因特征模型依然具有较强研究价值。

### 4.4.4 研究结论的合理性

综合实验结果可以认为，本文三条模型路线各有定位：

1. 基线模型适合作为稳定、可解释、易实现的初始对照组；
2. 模因特征模型适合作为面向特定目标场景的增强方案；
3. BERT 模型适合作为通用语义分类能力最强的高级模型方案。

因此，本文并不简单地以“哪一个模型指标最高”作为最终结论，而是从不同实验场景出发，对三种模型的适用性进行综合评价。这种分析方式更符合毕业设计论文对研究过程和结果解释的要求。

## 4.5 本章小结

本章围绕三种模型的实验结果展开分析，分别从正式测试集和人工测试集两个维度对其表现进行了比较。实验结果表明，BERT 在正式测试集上的整体指标最优，说明其在通用中文语义分类任务中具有较强优势；而模因式表达特征模型虽然在总体指标上不占优，但在特定目标场景下更贴近“文本模因识别”这一课题目标。

通过本章分析可以得出结论：在文本模因识别任务中，不能仅以总体分类指标作为唯一评价依据，还需要结合场景化样例进行补充分析。正式测试集结果和人工测试集结果共同构成了本文实验结论的基础，也为下一章的总结与展望提供了依据。
