# 人工测试集说明

## 1. 文件位置

- 测试集文件：[manual_test_set.csv](/d:/code/project-meme/data/manual_test_set.csv)

## 2. 用途

这份测试集是为当前毕业设计人工构造的补充测试集，主要用于：

- 对比基线模型、模因特征模型、BERT 模型在典型样例上的表现
- 观察模型在正常文本、显式攻击文本、模因式攻击文本、描述语境文本中的差异
- 为论文第 4 章“实验与结果分析”提供可解释的案例材料

## 3. 注意事项

这份测试集的定位是“人工构造样例集”，不是严格随机抽样的正式统计测试集。

因此建议：

- 用它做定性分析和案例分析
- 不要把它单独作为最终模型总体指标的唯一依据
- 最终总体指标仍以正式训练划分出的测试集结果为主

## 4. 字段说明

- `id`：样例编号
- `label`：预期标签，`0` 表示正常文本，`1` 表示疑似有害文本
- `category`：样例类别
- `text`：测试文本
- `expected_note`：该样例的设计意图

## 5. 类别分布

当前包含以下类别：

- `normal_plain`
- `anti_hate`
- `disagreement`
- `safe_meme`
- `explicit_harm`
- `meme_harm`
- `implicit_group_attack`

## 6. 建议使用方式

建议后续用三类模型分别跑这份测试集：

- 基线模型
- `meme_features_v1`
- `BERT`

然后整理成三模型对比表，重点观察：

- 哪些样例只有 BERT 能识别
- 哪些样例模因特征模型更贴题
- 哪些样例三种模型都容易出错
