# 模型说明

## 1. 当前模型是什么

当前系统目前已经形成了两版传统机器学习模型，不是大语言模型，也不是 `BERT`。核心思路如下：

- 基线版：`TF-IDF + Logistic Regression`
- 改进版：`TF-IDF + Meme Expression Features + Logistic Regression`

作用是对输入文本进行二分类：

- `0`：正常文本
- `1`：疑似有害文本

## 2. 当前模型怎么工作

可以把它理解成三个步骤：

1. 读取训练数据
2. 把文本转换成数字特征
3. 根据数字特征判断文本属于哪一类

### 2.1 数据读取与清洗

数据文件是 [data/data.csv](/d:/code/project-meme/data/data.csv)，当前主要使用两列：

- `label`
- `text`

训练前会进行以下处理：

- 删除空文本
- 删除非法标签
- 删除重复文本
- 保留二分类标签 `0` 和 `1`

### 2.2 TF-IDF 特征提取

`TF-IDF` 的作用是把文本转换成模型能处理的数字向量。

当前实现采用的是“字符级”特征，而不是分词级特征。也就是模型会关注：

- 单个字
- 连续两个字
- 连续三个字

这样做对中文短文本比较友好，也能减少复杂分词带来的误差。

### 2.3 模因式表达特征

为了让系统更贴近“文本模因识别”，当前在基线模型基础上补充了一组人工设计的表达特征，包括：

- 模板化表达特征
- 群体指向特征
- 情绪强化特征
- 嘲讽表达特征
- 对立结构特征
- 模因短语特征
- 标点爆发特征
- 重复字符特征
- 风险词与群体词共现特征
- 反对/缓和语境特征
- 描述/引用语境特征
- 分析语境特征

这些特征不会替代 `TF-IDF`，而是作为补充信息，和文本特征一起送入分类器。

### 2.4 语境消歧策略

为了减少“只要出现敏感词就被判为有害文本”的问题，当前系统加入了简单的语境消歧逻辑，将文本大致分为：

- 直接攻击语境
- 模因式攻击语境
- 描述/反对语境

例如：

- “我反对任何形式的歧视言论”更接近反对语境
- “这种说法像是在侮辱别人”更接近描述语境
- “这个群体根本不配得到尊重”更接近直接攻击语境

这种处理方式虽然还不是真正的深层语义理解，但能够明显改善部分典型误判。

### 2.5 Logistic Regression 分类

`Logistic Regression` 是一个二分类模型。它会根据训练数据学习：

- 哪些文本特征更像正常文本
- 哪些文本特征更像疑似有害文本

预测时会输出一个分数，再由程序判断最终标签。

## 3. 为什么它和“模因式表达”还不完全一样

当前模型本质上更接近“有害文本分类”，它能识别文本风险，但还没有完整建模“模因”这种可复制、可传播、模板化表达的特征。

所以现在这个系统更准确的定位是：

“面向文本模因场景的有害内容识别系统”

后续如果加入模板化表达、群体指向、情绪强化、嘲讽表达等特征，就会更接近“文本模因识别”。

## 5. 当前实验现象

目前已经观察到：

- 改进版模型在整体指标上暂时没有超过基线模型
- 但在“不是我说”“典中典”这类更接近网络模因表达的样例上，改进版模型更敏感
- 在加入语境消歧后，模型能够修正一部分“反对歧视”“描述侮辱行为”的误判

这说明“模因式表达特征”是有价值的方向，只是当前第一版特征设计仍然比较初步。

## 6. 当前模型产物

训练完成后，系统会输出以下文件：

- `back-end/artifacts/model.joblib`
- `back-end/artifacts/metrics.json`
- `back-end/artifacts/metadata.json`

含义如下：

- `model.joblib`：训练好的模型文件
- `metrics.json`：当前模型的准确率、精确率、召回率、F1
- `metadata.json`：样本数量、训练集规模、测试集规模、标签分布

## 7. 当前阶段为什么合理

对于本科毕业设计来说，先从传统机器学习模型入手是合理的，因为：

- 训练成本低
- 实现难度适中
- 容易搭建完整系统
- 容易形成基线模型
- 便于后续与 `BERT` 做对比

## 8. 后续改进方向

建议按以下顺序逐步升级：

1. 增加模因式表达特征
2. 比较改进前后的指标
3. 尝试 `BERT` 或 `RoBERTa`
4. 做多模型实验对比
