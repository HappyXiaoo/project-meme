# 测试样例

这份文档用于整理系统测试时使用的典型输入样例，后续可以直接截图、记录预测结果，并整理到论文测试章节。

## 使用方法

每次测试时，记录：

- 输入文本
- 预期结果
- 实际结果
- 模型分数
- 是否符合预期
- 备注

## 四、当前观察

- 当前模型对明显攻击性文本识别效果较稳定。
- 当前模型对“反对歧视”“描述侮辱行为”这类文本存在误判。
- 当前模型对带有网络梗、模板化表达、隐含攻击性的文本还不够敏感。
- 这些现象可以作为后续加入“模因式表达特征”的依据。
