# 测试样例

这份文档用于整理系统测试时使用的典型输入样例，后续可以直接截图、记录预测结果，并放进论文测试章节。

## 使用方法

每次测试时，记录：

- 输入文本
- 预期结果
- 实际结果
- 模型分数
- 是否符合预期
- 备注
