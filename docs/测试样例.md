# 测试样例

这份文档用于整理系统测试时使用的典型输入样例，后续可以直接截图、记录预测结果，并整理到论文测试章节。

## 使用方法

每次测试时，记录：

- 输入文本
- 预期结果
- 实际结果
- 模型分数
- 是否符合预期
- 备注

## 四、当前观察

- 当前模型对明显攻击性文本识别效果较稳定。
- 当前模型已经可以区分一部分“反对语境”“描述语境”和“直接攻击语境”。
- 当前模型对模板化、网络化、带有群体指向的表达更敏感。
- 后续仍需继续观察是否出现新的漏判或过判。
