## 四、当前观察

- 当前模型对明显攻击性文本识别效果较稳定。

- 当前模型对模板化、网络化、带有群体指向的表达更敏感。
- 后续仍需继续观察是否出现新的漏判或过判。

## 七、BERT 本地测试记录建议

在正式 GPU 训练前，建议先做一次本地小样本试跑，并记录以下内容：

- 是否成功加载 tokenizer
- 是否成功加载预训练模型
- 是否成功完成至少 1 个 epoch 或 1 次评估
- 是否成功输出模型目录、`metrics.json`、`metadata.json`
- CPU 试跑的大致耗时
- 是否遇到依赖、内存或版本问题

本地 smoke test 建议命令：

```bash
cd back-end
python scripts/train_bert.py --smoke-test --cpu-only --train-sample-limit 128 --eval-sample-limit 64
```

## 八、人工测试集三模型对比结论

基于 [manual_test_set.csv](/d:/code/project-meme/data/manual_test_set.csv) 的对比结果，当前三种模型呈现出以下特点：

- 基线模型总体准确率：0.7667
- `meme_features_v1` 总体准确率：0.7333
- `BERT` 总体准确率：0.6000

按类别观察：

- 在 `normal_plain`、`anti_hate`、`disagreement`、`safe_meme` 这几类样例上，三种模型整体表现都较稳定。
- 在 `explicit_harm` 类样例上，BERT 并非全部正确，说明总体测试集指标高并不代表对人工构造风险样例一定更强。
- 在 `meme_harm` 和 `implicit_group_attack` 两类样例上，BERT 明显弱于前两种模型，说明当前 BERT 更擅长常规语义分类，但对模因式攻击表达和隐含群体攻击表达的适配不足。
- `meme_features_v1` 虽然总体准确率不最高，但在与课题更贴近的模因式表达样例上更有针对性。

这组结果说明：

- 正式测试集指标和人工目标场景测试集表现可能不一致。
- BERT 更适合作为“总体性能较强”的语义基线。
- 模因特征模型虽然总体指标略低，但在“文本模因识别”这一特定场景下具有更强解释力。
