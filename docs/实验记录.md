## 实验 01：基线系统与基线模型

- 日期：2026-04-17
- 实验名称：基线系统搭建与基础文本分类模型
- 实验目的：构建一个可运行、可训练、可保存、可加载、可预测的毕业设计基础版本，为后续“模因式表达特征”和 `BERT` 模型实验提供对比基线。
- 系统实现范围：
  - 完成前端页面原型搭建
  - 完成后端接口开发
  - 完成前后端联调
  - 完成基线模型训练、保存与加载
- 模型方案：`TF-IDF + Logistic Regression`
- 数据来源：[data/data.csv](/d:/code/project-meme/data/data.csv)
- 训练脚本：[train_model.py](/d:/code/project-meme/back-end/scripts/train_model.py)
- 模型服务：[classifier.py](/d:/code/project-meme/back-end/app/services/classifier.py)
- 模型产物目录：`back-end/artifacts/`
- 数据规模：
  - 总样本数：13471
  - 训练集：10776
  - 测试集：2695
  - 标签分布：`0 -> 7904`，`1 -> 5567`
- 评价指标：
  - accuracy：0.8223
  - precision：0.7754
  - recall：0.8025
  - f1：0.7887
- 当前实现说明：
  - 使用中文字符级 `TF-IDF` 提取文本特征
  - 使用 `Logistic Regression` 完成二分类
  - 模型训练完成后保存为 `model.joblib`
  - 同步保存 `metrics.json` 和 `metadata.json`
  - 后端启动时优先加载已训练模型
  - 对明显攻击性文本叠加了风险关键词增强策略，以提升演示稳定性
- 阶段成果：
  - 系统已经具备完整的输入、预测、展示流程
  - 后端可以通过接口返回真实预测结果
  - 当前模型已经可以作为后续改进实验的正式基线
- 当前不足：
  - 当前模型更接近“有害文本识别”，与“模因识别”的联系还不够强
  - 还没有引入模板化表达、群体指向、情绪强化等模因式表达特征
  - 还没有与预训练模型进行对比
- 当前结论：
  - 基线系统已经搭建完成
  - 基线模型指标可接受，适合作为后续改进实验的对照组
  - 下一阶段应重点补充“模因式表达特征”，提高系统与课题题目的贴合度
- 下一步计划：
  - 增加模板化表达、群体指向、情绪强化、嘲讽表达等特征
  - 对比加入模因式表达特征前后的指标变化
  - 尝试 `BERT` 或 `RoBERTa` 作为进一步优化方案

## 实验 02：模因式表达特征

- 日期：2026-04-17
- 实验名称：模因式表达特征增强模型
- 实验目的：在基线文本分类模型的基础上，引入模板化表达、群体指向、情绪强化、嘲讽表达等特征，使模型更贴近“文本模因识别”场景，并观察其对整体指标和典型样例的影响。
- 模型方案：`TF-IDF + Meme Expression Features + Logistic Regression`
- 数据来源：[data/data.csv](/d:/code/project-meme/data/data.csv)
- 训练脚本：[train_model.py](/d:/code/project-meme/back-end/scripts/train_model.py)
- 实现位置：[classifier.py](/d:/code/project-meme/back-end/app/services/classifier.py)
- 数据规模：
  - 总样本数：13471
  - 训练集：10776
  - 测试集：2695
- 评价指标：
  - accuracy：0.8219
  - precision：0.7861
  - recall：0.7819
  - f1：0.7840
- 关键改动：
  - 保留基线的字符级 `TF-IDF` 特征
  - 新增模因式表达特征提取器
  - 将人工特征与 `TF-IDF` 特征拼接后输入 `Logistic Regression`
  - 当前加入的特征包括：
    - 模板化表达特征
    - 群体指向特征
    - 情绪强化特征
    - 嘲讽表达特征
    - 对立结构特征
    - 模因短语特征
    - 标点爆发特征
    - 重复字符特征
    - 风险词与群体词共现特征
- 样例观察：
  - 对样例“不是我说，某些人真的是典中典。”，基线模型判为正常文本，改进模型判为疑似有害文本
  - 说明加入模因式表达特征后，模型对模板化、网络化表达的敏感度有所提升
  - 但对“我反对任何形式的歧视言论。”这类含敏感词但语义并非攻击的文本，误判问题仍然存在
- 当前结论：
  - 从整体指标看，`meme_features_v1` 暂时没有超过基线模型
  - 从典型样例看，改进模型已经开始捕捉部分模因式表达模式
  - 这说明模因式表达特征是有效方向，但当前特征设计仍需继续优化
- 下一步计划：
  - 继续扩充模板化表达和网络梗表达特征
  - 优化对“描述性语句”和“反对性语句”的误判问题
  - 尝试引入 `BERT` 进行语义层面对比

### 实验 02 的继续优化：语境消歧

- 日期：2026-04-17
- 优化目的：修正“反对歧视”“描述侮辱行为”这类文本被敏感词规则误判的问题。
- 关键改动：
  - 增加“反对/缓和语境”词特征，如“反对”“抵制”“谴责”“避免”等
  - 增加“描述/引用语境”词特征，如“言论”“说法”“行为”“审核”“讨论”等
  - 增加“分析语境”词特征，如“像是”“带有”“属于”“涉嫌”等
  - 将后处理逻辑拆成“直接攻击语境”“模因式攻击语境”“描述/反对语境”三类，而不是只要命中敏感词就直接判为风险文本
- 优化后指标：
  - accuracy：0.8200
  - precision：0.7831
  - recall：0.7810
  - f1：0.7820
- 样例观察：
  - “我反对任何形式的歧视言论。”：优化后由风险文本修正为正常文本
  - “这种说法像是在侮辱别人。”：优化后由风险文本修正为正常文本
  - “不是我说，某些人真的是典中典。”：优化后仍可识别为疑似有害文本
  - “果然某些人又开始这一套了，笑死。”：优化后可以识别为更隐含的模因式攻击表达
- 当前结论：
  - 总体指标略有下降，但目标场景下的误判修复明显
  - 当前优化更强调“课题贴合度”和“样例解释力”，而不是只追求总体分数
  - 这一阶段的变化非常适合写进论文中的实验分析部分
- 下一步计划：
  - 继续细化语境规则，防止修复误判的同时引入新的漏判
  - 记录更多模因式表达样例
  - 进入 `BERT` 对比实验阶段
