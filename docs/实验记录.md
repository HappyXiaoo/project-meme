## 实验 01：基线模型

- 日期：2026-04-17
- 实验名称：基线文本分类模型
- 实验目的：构建一个可训练、可保存、可加载、可预测的基础模型，作为后续“模因式表达特征”和 `BERT` 模型的对比基线
- 模型方案：`TF-IDF + Logistic Regression`
- 数据来源：[data/data.csv](/d:/code/project-meme/data/data.csv)
- 训练脚本：[back-end/scripts/train_model.py](/d:/code/project-meme/back-end/scripts/train_model.py)
- 模型服务：[back-end/app/services/classifier.py](/d:/code/project-meme/back-end/app/services/classifier.py)
- 模型产物目录：`back-end/artifacts/`
- 数据规模：
  - 总样本数：13471
  - 训练集：10776
  - 测试集：2695
  - 标签分布：`0 -> 7904`，`1 -> 5567`
- 评价指标：
  - accuracy：0.8223
  - precision：0.7754
  - recall：0.8025
  - f1：0.7887
- 当前实现说明：
  - 使用中文字符级 `TF-IDF` 提取文本特征
  - 使用 `Logistic Regression` 完成二分类
  - 模型训练完成后保存为 `model.joblib`
  - 同步保存 `metrics.json` 和 `metadata.json`
  - 后端启动时优先加载已训练模型
  - 对明显攻击性文本叠加了风险关键词增强策略
- 当前结论：
  - 系统已经具备基础文本分类能力
  - 可以稳定作为后续改进实验的对比基线
  - 后续重点方向是补充“模因式表达特征”并尝试 `BERT`
- 下一步计划：
  - 增加模板化表达、群体指向、情绪强化、嘲讽表达等特征
  - 对比加入模因式表达特征前后的指标变化
  - 继续尝试预训练模型方案
