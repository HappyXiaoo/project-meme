## 实验 01：基线系统与基线模型

- 日期：2026-04-17
- 实验名称：基线系统搭建与基础文本分类模型
- 实验目的：构建一个可运行、可训练、可保存、可加载、可预测的毕业设计基础版本，为后续“模因式表达特征”和 `BERT` 模型实验提供对比基线。
- 系统实现范围：
  - 完成前端页面原型搭建
  - 完成后端接口开发
  - 完成前后端联调
  - 完成基线模型训练、保存与加载
- 模型方案：`TF-IDF + Logistic Regression`
- 数据来源：[data/data.csv](/d:/code/project-meme/data/data.csv)
- 训练脚本：[train_model.py](/d:/code/project-meme/back-end/scripts/train_model.py)
- 模型服务：[classifier.py](/d:/code/project-meme/back-end/app/services/classifier.py)
- 模型产物目录：`back-end/artifacts/`
- 数据规模：
  - 总样本数：13471
  - 训练集：10776
  - 测试集：2695
  - 标签分布：`0 -> 7904`，`1 -> 5567`
- 评价指标：
  - accuracy：0.8223
  - precision：0.7754
  - recall：0.8025
  - f1：0.7887
- 当前实现说明：
  - 使用中文字符级 `TF-IDF` 提取文本特征
  - 使用 `Logistic Regression` 完成二分类
  - 模型训练完成后保存为 `model.joblib`
  - 同步保存 `metrics.json` 和 `metadata.json`
  - 后端启动时优先加载已训练模型
  - 对明显攻击性文本叠加了风险关键词增强策略，以提升演示稳定性
- 阶段成果：
  - 系统已经具备完整的输入、预测、展示流程
  - 后端可以通过接口返回真实预测结果
  - 当前模型已经可以作为后续改进实验的正式基线
- 当前不足：
  - 当前模型更接近“有害文本识别”，与“模因识别”的联系还不够强
  - 还没有引入模板化表达、群体指向、情绪强化等模因式表达特征
  - 还没有与预训练模型进行对比
- 当前结论：
  - 基线系统已经搭建完成
  - 基线模型指标可接受，适合作为后续改进实验的对照组
  - 下一阶段应重点补充“模因式表达特征”，提高系统与课题题目的贴合度
- 下一步计划：
  - 增加模板化表达、群体指向、情绪强化、嘲讽表达等特征
  - 对比加入模因式表达特征前后的指标变化
  - 尝试 `BERT` 或 `RoBERTa` 作为进一步优化方案
