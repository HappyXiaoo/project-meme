# Meme Features V1

当前目录用于保存“模因式表达特征”第一版实验材料。

## 当前特征方向

- 模板化表达特征
- 群体指向特征
- 情绪强化特征
- 嘲讽表达特征
- 对立结构特征
- 模因短语特征
- 标点爆发特征
- 重复字符特征
- 风险词与群体词共现特征

## 当前结果

- baseline
  - accuracy: 0.8223
  - precision: 0.7754
  - recall: 0.8025
  - f1: 0.7887
- meme_features_v1
  - accuracy: 0.8219
  - precision: 0.7861
  - recall: 0.7819
  - f1: 0.7840

## 当前观察

- 第一版模因式表达特征尚未在总体指标上超过基线模型
- 但在“不是我说”“典中典”等模板化样例上，模型已经表现出更高敏感度
- 后续仍需要继续优化特征设计，并考虑引入 `BERT` 做进一步对比
